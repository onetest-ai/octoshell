# M7 manual F5 script: T7.4 AC2 / M7 TC-007

Checks the install prompt (Reconcile / Overwrite / Keep mine / Cancel) in a real Extension Development
Host, on a COPY of solo. Your solo checkout ($SOLO) is never opened or written. Expect about 15 minutes.

## 0. Prepare (terminal)

```bash
export SOLO=/Users/arozumenko/Development/auqanautica OCTO=/Users/arozumenko/Development/octoshell
export WORK=$(mktemp -d) EV=$OCTO/.octobots/campaigns/direct-dispatch-process/tests/m7/evidence
mkdir -p "$EV"
gitcopy() { git clone -q --shared --no-checkout "$SOLO" "$WORK/$1" && git -C "$WORK/$1" checkout -q HEAD -- .claude .octobots && cp -R "$SOLO/.claude" "$SOLO/.octobots" "$SOLO/CLAUDE.md" "$SOLO/AGENTS.md" "$WORK/$1/"; }
gitcopy solo-f5
W=$WORK/solo-f5; echo "workspace: $W"
grep -m1 '^version:' $W/.claude/skills/*/SKILL.md     # expect mission-execution and mission-completion-gate at 57-local
ls $W/.octobots/pack-updates 2>/dev/null || echo "no pack-updates (good)"
(cd $W && find .claude .octobots -type f | sort | xargs shasum -a 256) > $WORK/f5.sha
echo OCTO-F5-SENTINEL | pbcopy                        # clipboard sentinel
cd $OCTO && git checkout feat/direct-dispatch-process-m7-t4 && pnpm build
```

## 1. Launch the dev host on the copy

1. Open $OCTO in VS Code. Run and Debug, pick **Run Octoshell Extension**, press F5.
2. In the Extension Development Host window: File > Open Folder..., choose the `$W` path printed above.
   The window reloads on the copy.

## 2. Activation prompt, then Cancel (AC4: modal first, Cancel writes nothing)

3. A bottom-right notification appears:
   `Octobots pack isn't up to date for this repo. Update it so planning agents understand campaigns/missions/tasks?`
   with the buttons **Install** and **Not now**. Screenshot: `TC-007-01-activation.png`. Click **Install**.
4. A MODAL dialog appears BEFORE any hooks or tools question. Check it character for character:
   - Message: `Octobots: 2 pack skill(s) in this workspace were changed locally.`
   - Detail:
     ```
     Installing the Octobots pack v57 would replace or delete these skills:
     • mission-execution: version 57-local (not a pack version)
     • mission-completion-gate: version 57-local (not a pack version)
     Reconcile: install everything else and stage these skills in .octobots/pack-updates/v57/; your next agent session merges them with the octobots-doctor skill.
     Overwrite: replace them with the pack's files.
     Keep mine: install everything else and leave these skills as they are.
     Cancel: install nothing.
     ```
   - Buttons: **Reconcile** (first, the highlighted default), **Overwrite**, **Keep mine**, **Cancel**.
   - workflow-designer and mission-planner are NOT listed (they are pristine v56).
   Screenshot: `TC-007-02-modal.png`.
5. Click **Cancel**. (Escape should do the same; to try it too, re-run step 6's command, press Esc, and re-check.)
   Expected: no further question and no notification. Nothing else appears.
   In the terminal:
   ```bash
   (cd $W && shasum -a 256 -c $WORK/f5.sha | grep -v ': OK$'); (cd $W && find .claude .octobots -type f | wc -l); wc -l < $WORK/f5.sha
   ls $W/.octobots/pack-updates 2>/dev/null || echo "no pack-updates (good)"
   ```
   Expected: the shasum line prints nothing, the two counts are equal, and there's no pack-updates folder.
   Screenshot of the terminal: `TC-007-03-cancel-nothing-written.png`.

## 3. Install command, Enter = Reconcile (AC4: default, completion text, no agent)

6. Press Cmd+Shift+P and run **Octobots: Install Octobots Pack**. The same modal appears. Press
   **Enter** without clicking anything.
7. Solo's copy already registers the session hooks and has ccusage, so normally NEITHER the hooks question
   NOR the tools question appears. The install runs at once; it refreshes ccusage, so expect a short pause that needs the network.
   A harness dry run on a copy, made 2026-10-05, gave 38 files with hooks and tools refreshed.
8. The completion notification must read exactly as follows (only the file count `<n>` varies; 38 expected):
   `Octobots: pack installed (<n> files) with session hooks and tokenomics CLI. Staged mission-execution, mission-completion-gate for reconcile in .octobots/pack-updates/v57/. The next agent session will be asked to run the octobots-doctor skill.`
   If the hooks question DID appear and you clicked **Skip hooks**, the text drops ` with session hooks`
   and ends with ` The SessionStart hook is off, so ask your agent to run octobots-doctor.` (That variant
   is also pinned by the vitest.)
   Screenshot: `TC-007-04-reconcile-done.png`.
9. Check that no terminal, chat panel or agent opened (screenshot the whole window: `TC-007-05-no-agent.png`). In the terminal:
   ```bash
   pbpaste                                              # expect OCTO-F5-SENTINEL
   grep -m1 '^version:' $W/.claude/skills/mission-execution/SKILL.md $W/.claude/skills/mission-completion-gate/SKILL.md   # both 57-local
   ls $W/.octobots/pack-updates/v57/*/                  # base.md local.md upstream.md RECONCILE.md per skill
   cat $W/.octobots/pack-updates/pending.json           # packVersion 57, 2 skills, kept []
   ```

## 4. Activation stays quiet while pending, then asks on a changed fork

10. Cmd+Shift+P, **Developer: Reload Window**. Expected: NO Octobots activation notification. Wait about 10 s.
    Screenshot: `TC-007-06-reload-quiet.png`.
11. In the terminal: `echo "One more local rule." >> $W/.claude/skills/mission-execution/SKILL.md`, then reload the window.
    Expected: the activation notification from step 3 shows again (the pending sha256 no longer matches).
    Screenshot: `TC-007-07-reprompt-changed-sha.png`. Click **Not now**.

## 5. Keep mine is remembered (T7.4 AC3)

12. Run **Octobots: Install Octobots Pack**. Expected: the modal asks again, because the Install command always asks. Click **Keep mine**.
    The completion message has no "Staged" sentence. In the terminal:
    `cat $W/.octobots/pack-updates/pending.json`. Expected: `"skills": []` and `kept` holds both skills with `"packVersion": 57`.
    `ls $W/.octobots/pack-updates/v57/*/ 2>/dev/null`. Expected: none of base.md, local.md, upstream.md or RECONCILE.md remain.
    Screenshot: `TC-007-08-keep.png`.
13. Reload the window. Expected: NO activation notification. Screenshot: `TC-007-09-keep-quiet.png`.
14. Optional, for AC3's default-install half: run the harness default (no flag) on the same copy:
    `node $OCTO/apps/vscode-extension/scripts/qa/install-pack.mjs $W > $WORK/def.json`. Expected: exit 0, empty stderr,
    `result.pending` `[]`, and `result.kept` lists both skills. Reload the window. Expected: still no activation notification.
